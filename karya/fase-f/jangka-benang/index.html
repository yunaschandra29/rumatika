Bagaimana tukang taman menggambar kolam?

Tanpa jangka raksasa, tukang taman menancapkan satu patok, mengikat tali, lalu berjalan memutar sambil menarik tali tetap tegang. Hasilnya: lingkaran.

Untuk kolam oval, ia memakai dua patok dan tali yang ujungnya diikat ke keduanya. Hasilnya: elips.

Keduanya bergantung pada jarak antara dua titik. Kita cek dulu bekalmu.

Setelah bab ini, kamu mampu:
1. menyusun persamaan lingkaran dan elips dari unsur-unsurnya;
2. menentukan unsur lingkaran dan elips dari persamaannya;
3. menentukan kedudukan titik dan garis terhadap lingkaran;
4. menentukan persamaan garis singgung lingkaran dan memakainya dalam masalah nyata.

Rangkuman: Satu Halaman Catatan

Lingkaran

x² + y² = r²
(x − a)² + (y − b)² = r²
x² + y² + Ax + By + C = 0

Pusat (−A/2, −B/2), r = √(A²/4 + B²/4 − C)

Elips

x²/a² + y²/b² = 1  (a > b)

Mayor tegak: a² di bawah y². Pusat (h,k): ganti x → x − h, y → y − k.

c² = a² − b², e = c/a

Jumlah jarak ke dua fokus selalu 2a.

Kedudukan

Titik: hitung K = (p − a)² + (q − b)² − r².
K < 0 dalam · K = 0 pada · K > 0 luar

Garis: substitusi → D, atau jarak d pusat ke garis.
D > 0 / d < r memotong · D = 0 / d = r menyinggung · D < 0 / d > r terpisah

Garis Singgung Lingkaran

Titik T(x₁, y₁) pada lingkaran
x₁x + y₁y = r²
(x₁ − a)(x − a) + (y₁ − b)(y − b) = r²
Gradien m diketahui
y = mx ± r√(1 + m²)
y − b = m(x − a) ± r√(1 + m²)
Titik P di luar
y − y₁ = m(x − x₁), syarat d = r
Panjang PT = √(|PO|² − r²)
